# Archived planning documents

These are dated snapshots kept for provenance. They describe the corpus and its tooling at the date in each filename and are not current guidance.

- `mei-finalization-assessment-2026-09-29.md`: the initial review of the Op. I/1 pilot, its header, the validators and the BSB IIIF metadata, which led to the plan below.
- `finalization-plan-2026-10-01.md`: the ordered finalization plan, including the scan-format and image-storage recommendations. Steps 1–3 (validation boundary, shared CAMAT checks and this corpus's validator) are complete.

The open items for the first stable release are in the [1.0 checklist](../../finalization-plan.md). Current validation behaviour is described in [the tool guide](../../../validation/README.md).
