# DdT 1, Vol. 11 — 0.9.0 (pre-release)

This is the first public release of the MEI edition of *Dietrich Buxtehudes Instrumentalwerke* (Denkmäler deutscher Tonkunst, first series, vol. 11, ed. Carl Stiehl, 1903). It contains 16 of the volume's 17 works as complete MEI 5.1 files, each measure linked to the Bayerische Staatsbibliothek facsimile.

**Status: corrected, not finalized.** The musical text and the facsimile links of every included work have been reviewed against DdT 1903, and their consistency reports are complete. Publication sign-off, final filenames and the release-mode gate are still open; the [1.0 checklist](https://github.com/egorpol/DdT_1_vol_11/blob/v0.9.0/docs/finalization-plan.md) lists what remains. The files can be used and cited now, but details may change before 1.0. Each change will be listed in the [changelog](https://github.com/egorpol/DdT_1_vol_11/blob/v0.9.0/CHANGELOG.md).

Beside each score is its consistency report (`*_consistency_report.csv`).

## Using the edition

### Choosing staves for analysis

The files keep DdT's printed score, including the two-staff keyboard realization of the figured bass that the 1903 edition added. This realization is DdT's, not Buxtehude's. State which view an analysis uses:

- **Solo parts and continuo:** staves 1–3 (violin, viola da gamba, figured bass), or staves 1–4 in App. II (two violins, gamba, figured bass). In App. III, staves 1–3 are gamba, violone and figured bass.
- **DdT's complete texture:** all staves, including the two realization staves (4–5, or 5–6 in App. II).

Per-work staff roles are listed under `staff_roles` in [`validation/editorial-works.json`](https://github.com/egorpol/DdT_1_vol_11/blob/v0.9.0/validation/editorial-works.json). A selection of the solo and continuo staves still comes from this corrected DdT text: it is not a transcription of the original partbooks. See the [editorial policy](https://github.com/egorpol/DdT_1_vol_11/blob/v0.9.0/docs/editorial-policy.md#staff-layout-and-analytical-views).

### Finding the facsimile

Every `measure/@facs` points to a measure zone on a `surface`. Each surface stands for one DdT page: its `@corresp` is the BSB IIIF canvas and its `graphic/@target` the IIIF image. Printed DdT page *p* is BSB image *p* + 10, so page 3 is image `00013`. The images stay on the BSB server; this repository does not copy them. The full digitized volume is at [digitale-sammlungen.de/en/view/bsb00023199](https://digitale-sammlungen.de/en/view/bsb00023199) (URN `urn:nbn:de:bvb:12-bsb00023199-0`).

To see score and facsimile side by side, open `mei_facsimile_viewer.ipynb` (requires CAMAT, see below), or load a file into [mei-friend](https://mei-friend.mdw.ac.at/). A web viewer is planned.

### Editorial annotations

Annotations sit inside the measure they concern, as `annot[@type='editorial']`. `@label` gives the category, `@plist` the affected events, `@resp` the responsible editor and `@source` the witness that attests the reading, if any. The categories are defined in the [editorial policy](https://github.com/egorpol/DdT_1_vol_11/blob/v0.9.0/docs/editorial-policy.md#correction-categories).

## Validation record

The consistency reports and their provenance, [`validation/editorial-reports.json`](https://github.com/egorpol/DdT_1_vol_11/blob/v0.9.0/validation/editorial-reports.json), come from a full run on 2026-10-21 in review mode:

- Software: [CAMAT](https://pypi.org/project/camat/) 0.2.7 from PyPI, Verovio 6.3.0, lxml 6.1.2, saxonche 13.0.0, Python 3.14. Official MEI 5.1 CMN schema, pinned in [`schemas/`](https://github.com/egorpol/DdT_1_vol_11/tree/v0.9.0/schemas) (SHA-256 `f6440d5e…`). Edition profile `DdT_1_vol_11` 0.1.0 ([`validation/profile.json`](https://github.com/egorpol/DdT_1_vol_11/blob/v0.9.0/validation/profile.json)).
- All 16 files passed XML and reference checks, RELAX NG, Schematron, resource and image-URL checks, full Verovio rendering and CAMAT event parsing. Their hashes were unchanged after the run.
- The edition's publication rules return **needs-review** for all 16, as expected for unfinalized files. The reports contain 274 rows (264 `warning`, 10 `info`), all explained below under known limitations: 170 Schematron advisories on the IIIF canvas links plus 16 matching edition reminders, 78 short-voice warnings in the passages kept as `metcon="false"`, and 10 info rows on spelling or punctuation variants of tempo and other directions, such as `(Allegro.)` beside `Allegro`.
- The provenance file records each input and report hash, the CAMAT version and source hash, dependency versions and the checks that ran.

The release-mode gate was not applied: it accepts only finalized files with a recorded, hash-bound reviewer sign-off, which this pre-release does not claim.

To rerun the checks on this release:

```sh
pip install "camat[validation,test]==0.2.7" verovio==6.3.0 lxml==6.1.2 saxonche==13.0.0
python scripts/validate_corpus.py --manifest validation/editorial-works.json --mode review --verovio --camat-parse
python -m pytest -p no:cacheprovider -q tests
```

The checks also need libxml2's `xmllint` on `PATH`. The [tool guide](https://github.com/egorpol/DdT_1_vol_11/blob/v0.9.0/validation/README.md) explains each check and report column. An empty or passing report means only that the automated checks found nothing; it does not establish that every pitch, rhythm or figure matches the source.

## Known limitations

- **Not finalized.** No work has a reviewer sign-off, filenames keep `_corr`, and each header's `pubStmt/identifier[@type='URI']` points to the file on `main`, not to this release. Cite the release tag (below) for a fixed version.
- **Op. II/1 is missing.** Whether 1.0 covers 16 or 17 works is still open.
- **Selective witness comparison.** The edition is based on DdT 1903. The Uppsala prints and manuscript are cited for selected passages in Op. I/1, Op. II/2, Op. II/6 and App. II; no complete collation is claimed.
- **App. II, m. 156, violin II** is an interim conjectural emendation (annotation `ayvjvlf1` in the App. II file): one eighth rest is omitted to restore the 3/4 meter. The reading of the Uppsala manuscript has not been confirmed.
- **Measures marked `metcon="false"`** (28) are intentional: the 12 pickup and complementary ending measures of App. I, and Op. II/2 mm. 199–214, where a 12/8 part sounds against common-time accompaniment. They account for the 78 short-voice warnings in the reports; the MEI headers and annotations explain them.
- **IIIF canvas warnings.** The official Schematron reads `surface/@corresp` as a local ID and flags each external canvas URL, once per surface (170). How to treat them is a decision for 1.0; no waiver is configured.
- **Rendering in Verovio 6.3.0** (details in [`docs/issues.md`](https://github.com/egorpol/DdT_1_vol_11/blob/v0.9.0/docs/issues.md)):
  - the composer is missing from the generated page header in all 16 files (the header names him correctly);
  - Op. I/3, m. 17: one printed C4 notehead shared by two voices is drawn as two heads;
  - Op. I/7, m. 250: the parentheses around the 6–4–2 figure stack are drawn beside the top and bottom figures, not around the stack.
- **Images.** The STIMU 1991 scans of the Uppsala prints are not published; only the two one-measure excerpts in [`supplemental_material/`](https://github.com/egorpol/DdT_1_vol_11/tree/v0.9.0/supplemental_material) are included, under the quotation basis described there.
