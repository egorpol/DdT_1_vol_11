# Local STIMU/Uppsala facsimile images

Run `python scripts/convert_uppsala_scans.py` from the corpus repository.
The default creates full-resolution JPEG images and a conversion inventory
under `op1/` and `op2/`. TIFF masters remain in their delivered directories.

See [the conversion and source guide](../../docs/uppsala-facsimiles.md) for
commands, the identified STIMU 1991 edition, mixed introduction/title-page
spreads, image metadata and the pending redistribution assessment.
