# Archived Page-Level Progress Automation

This directory preserves the former anonymous page-level progress display and its implementation. The automation was retired on 2026-08-16 because editorial work and public progress reporting had moved to complete sonata- and appendix-level files.

The archive contains:

- `page-grid-2026-08-16.svg`: the final generated snapshot, reporting 104 edited pages, 74 present but not yet edited, and 5 missing pages in the 183-page image sequence;
- [`scripts/archive/update_readme_progress.py`](../../../scripts/archive/update_readme_progress.py): the former generator for the SVG and README block;
- `update-progress-grid.workflow.yml`: the former scheduled GitHub Actions workflow.

These files are retained for project provenance. They are not active, and the script still reflects the paths and README markers used by the former workflow. It must be adapted before reuse.
